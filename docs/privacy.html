Privacy Policy

Application: Synapse Vertex Automation | Effective Date: October 24, 2026 | Last Updated: October 2026

This Privacy Policy explains how Synapse Vertex Automation ("we", "us", or "our"), developed and maintained by Crhis Robles, accesses, collects, uses, and safeguards information when you connect your Google Account with our automated workflow system.

Google API Limited Use Disclosure:
Synapse Vertex Automation's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

1. Purpose of the Application

Synapse Vertex Automation is a private, self-hosted automation ecosystem built to streamline personal financial management and academic notification dispatching. It executes automated pipelines via a private instance of n8n hosted on dedicated cloud infrastructure (Oracle Cloud Infrastructure).

2. Google User Data We Access

Depending on the specific workflow authorized by the account owner, Synapse Vertex Automation may access the following Google user data:

  • Google Sheets API (https://www.googleapis.com/auth/spreadsheets): Used exclusively to read, append, and update tabular records in the user's private financial workbook (Aerarium — Tabula Financia), including recurring expenses, categories, debt maturities, and balance pacing.
  • Google Drive API (https://www.googleapis.com/auth/drive.file): Used solely to access and manage the specific spreadsheets created by or explicitly opened with the application for backup and synchronization purposes.
  • Gmail API / Academic Notifications (https://www.googleapis.com/auth/gmail.readonly): Used exclusively to inspect incoming Google Classroom academic notifications (assignments, due dates, and course announcements) to generate structured alert summaries for authorized family communication channels (WhatsApp / Telegram).

3. How We Use and Process Data

All data retrieved from Google APIs is processed strictly according to the following principles:

  • Real-Time Pipeline Execution: Data is read in real time to perform mathematical calculations (e.g. burn rate, cash flow margins) or format text summaries.
  • Zero Data Selling: We do not sell, rent, lease, or monetize user data under any circumstances.
  • Zero Advertising & Profiling: User data is never used for advertising, behavioral profiling, marketing, or audience targeting.
  • No Human Inspection: No human reads private email messages or spreadsheet data, except when the account owner directly inspects execution logs in their private administrative console for troubleshooting.

4. Data Sharing and Third-Party Transfer

We do not transfer or share your Google user data with any third parties, except in the following strictly limited circumstance:

  • AI Summarization Subprocessors: Email notification text from Google Classroom may be transmitted via encrypted TLS API calls to the Google Gemini API (or Groq API failover) strictly for real-time text summarization and extraction of assignment deadlines. These subprocessors do not retain or use customer data to train generalized AI models.

5. Data Storage, Security, and Retention

Synapse Vertex Automation is designed with a minimal data footprint architecture:

  • No External Database Storage: Google user data is not permanently stored on external third-party servers. Your spreadsheet and email data remain securely stored within your own Google Account.
  • Private Cloud Infrastructure: All automated workflow execution occurs on the developer's secured Oracle Cloud instance, protected by HTTPS/TLS encryption and strict key-based authentication.
  • Temporary Log Retention: Workflow execution logs in n8n are automatically pruned and retained only for short-term operational debugging (maximum 7 days).

6. How to Revoke Access and Delete Data

You have full control over the permissions granted to Synapse Vertex Automation at all times:

  • You can revoke access immediately at any time by visiting your Google Account Permissions page: https://myaccount.google.com/permissions.
  • Upon revoking access, our application permanently loses the ability to access any Google APIs or refresh access tokens.
